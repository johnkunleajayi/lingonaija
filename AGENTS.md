# LingoNaija contributor guidance
This Desktop folder is the only official workspace. Keep frontend/ and backend/ as a simple modular monolith. Use environment variables and never commit secrets. Preserve original artwork and respectful, modern cultural presentation. Course data and progress are explicitly mocked. Future persisted learner records must belong to an individual User; never use a global user identity. Normalize emails before writing future authentication records. Do not add Google authentication, AI, speech recognition, audio, full lessons, XP or streak services without explicit scope. Run frontend tests/build and backend tests after changes. No commits or pushes without user instruction.
